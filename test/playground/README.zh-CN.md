# 交互工作台

开发时运行 `npm run dev`，打开 `http://127.0.0.1:5173/`；静态构建后，`dist/playground/index.html` 是入口，`/test/` 保留完整组件画廊。工作台把可编辑的 DSL 文本和真实解析器、运行时、React 渲染结果放在同一页。

| 场景 | 来源 | 可验证的交互 |
| --- | --- | --- |
| 费用计算器 | 第二份文本，示例一的可执行区段摘录 | 滑块、价格输入及派生费用更新 |
| 任务表单 | 第二份文本，示例二的可执行区段摘录 | 单选、下拉、勾选、条件块与新对话请求预览 |
| 周度趋势 | 第二份文本，示例三的可执行区段摘录 | 8 周 / 4 周切换，本地折线图重绘 |
| 控件集锦 | 最新清单，第五节的可执行区段摘录 | 多种表单值、计数按钮及确认后复制 |
| Agent 评测台 | 第一份受污染面板的**人工改编**，源码见 `benchmark-adapted.iui.txt` | 模拟排名、详情、柱图及复制；分数不代表真实表现 |
| 俄罗斯方块 | 第四份抓包中 assistant 消息的 AppBlock 子集；本地对碰撞/旋转/消行代码做可测重构 | 明确运行后自动下落、键盘/指针按钮、暂停、重开、消行计分、下块预览 |
| 交互式画板 | 第五份模型回答的 **Markdown 代码围栏内声明**，不证明原网页已运行 | 明确运行后颜色、笔刷、画布指针、清空；修复首次尺寸为零 |

选择场景会创建独立消息实例。编辑文本后约 180 毫秒解析；完整输入更新右侧并保留同名状态变量，未闭合或无效输入显示行列诊断并保留最后一次有效预览。“重置状态”恢复当前声明初值，“新实例”隔离全部状态并重新生成。`GenUI.issueNewTurn` 在本地只预览并反馈未配置，绝不发送。`GenUI.copy` 需要控件点击和弹窗确认。

原始输入与身份记录不随公开仓库发布。最新文件尾部在 popover 标签中途截断；工作台采用它此前完整的控件区段，另以合成样例验证截断诊断。

两个 AppBlock 都只在本地 `authorizeAppBlock` 精确匹配已审阅内容后提供“运行”。它们使用 `iframe sandbox="allow-scripts"`、拒网 CSP 和宿主自备的最小样式，关闭或重启会销毁旧 iframe。左侧任意改动脚本均不会自动执行，且不再满足已审阅样本匹配。完整边界见[AppBlock 说明](../../docs/APPBLOCK.zh-CN.md)。
