# 默认组件视觉依据

本轮依据用户提供的 ChatGPT 保存页做静态观察。分析时保留原始文件，只在系统临时目录生成移除脚本与 iframe、禁止网络请求的副本；没有把网页、资源目录、账户信息或聊天元数据加入仓库。静态快照能证明已保存 DOM 的排版与 CSS，不能证明原站的动画、全部交互行为或其他主题。

| 已观察到的参考样式 | 本项目处理 |
| --- | --- |
| 智能界面正文 16px / 26px，标题 18px / 28px、600 字重，说明文字 14px | 默认组件使用对应文字层级；协议 `size` 映射为 12/14/16/18/20/24px |
| 正文近黑色、次要文字灰色，页面近白；1px、约 10% 黑色的细边框，少用投影 | Studio 浅色主题改用中性表面、轻边框与低强度阴影；深色主题使用同一层级关系 |
| 主容器 16px 内边距、16px 间隔、16px 圆角；卡片可到 24px 圆角 | 显式 `padding` / `gap` 改按 4px 基础单位计算；卡片和默认间隔保留主题变量 |
| 按钮约 36px 高、14px 中字重；输入约 40px 高、16px 字体；圆形勾选/单选 20px | 统一原生按钮、输入、多行输入、下拉、单选、勾选、滑块、分段选择的尺寸和焦点态 |
| 徽标 12px/20px、柔和底色；可点行约 8px 圆角，表格强调水平分隔 | 对应调整徽标、Pressable、表格、代码区、弹出层及媒体表面 |

共享样式在 [`ui/styles.css`](../ui/styles.css)，颜色与主题参数在 [`ui/theme/index.tsx`](../ui/theme/index.tsx)，协议尺寸和间距映射在 [`ui/renderer/Renderer.tsx`](../ui/renderer/Renderer.tsx)。Gallery、组装演示和扩展回复渲染都使用这套组件样式。Citrus 仍保留独立字族、配色和圆角。没有引入外部字体或运行依赖，也没有修改协议语法、事件执行或媒体资源权限。

验证范围：本地构建后的 gallery 和 benchmark、费用计算器、图片演示在隔离 Chrome 中检查桌面与 390px 宽度；检查了 Studio 明暗、Citrus 浅色、焦点可见环、悬停、禁用、解析错误和水平溢出。真实 ChatGPT 页面只作为静态样式参考，真实 DeepSeek 网站仍需安装后验证。
