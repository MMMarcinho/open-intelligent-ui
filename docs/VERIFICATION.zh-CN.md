## 实际浏览器

在 Codex 内置浏览器打开本地构建版，并以真实页面操作验证：

- 桌面 1280px：七个场景可切换。俄罗斯方块需外层明确点击“运行”，再点击内部“开始游戏”；键盘方向键、空格、P 与屏幕方向按钮均产生游戏状态变化。硬降后得分从 0 变为 31；暂停状态可见。
- 修改左侧游戏脚本后，授权器拒绝重新运行。未经审阅的新脚本没有进入 iframe。
- 移动 390×844：文档 `scrollWidth` 与 `innerWidth` 均为 390，没有横向溢出。触控按钮的浏览器点击使俄罗斯方块开始、移动并硬降，得分变为 36。
- 移动端点击外层“重启”后，游戏回到“准备开始”、得分归零；点击“停止”后页面 iframe 数量为 0。
- 画板桌面运行后，其画布有非零实际尺寸；选色、笔刷调节、画布点击绘制和清空均在页面可见。移动端 390px 宽也显示了颜色按钮、笔刷滑块和画布，无横向溢出。
- 实际 iframe 属性为 `sandbox="allow-scripts"` 和 `referrerPolicy="no-referrer"`，生成的 `srcDoc` 含拒网 CSP；页面错误级控制台日志为空。

桌面和移动截图已由浏览器工具现场捕获，未导出为独立图片文件。上述验证不等于恶意脚本的资源隔离证明；沙箱没有 CPU/内存配额。画板验证了指针点击及清空，未完成连续拖动手势的自动化验证。

## 环境限制

当前机器的外部 npm 注册表 DNS 不可达；`node_modules` 是指向本机已有依赖目录的临时符号链接。`npm install` 在干净机器上的完整重现尚未验证，项目也未生成 lockfile。Library 字节级 materialization 在传输阶段失败，但通过 Library 全文只读接口取得资料并保留了相应身份和必要子集。
